## 🚀 Featured Projects

### 🐦 [Twitter Claim Verifier](https://github.com/Usamamanzoor2/twitter-claim-verifier)
> AI-powered financial claim verification pipeline for X/Twitter

An end-to-end LangGraph pipeline that polls tweets from PostgreSQL, routes each through a **Gemma 4 LLM** gate, gathers evidence from SEC filings, news, insider transactions, and institutional ownership data, and writes a final verdict and credibility score back to the database. Includes future prediction handling, web search fallback (Groq/Gemini/DeepSeek), and a Dead Letter Queue for fault tolerance.

`LangGraph` `Gemma 4` `PostgreSQL` `FastAPI` `Playwright` `SEC EDGAR`

---

### 🐾 [WAF NLP Clustering](https://github.com/Usamamanzoor2/World_Animal_foundation_NLP_Clustering)
> Unsupervised NLP clustering for the World Animal Foundation

Applied TF-IDF vectorization and clustering algorithms (K-Means, DBSCAN) to organize large volumes of unstructured animal welfare text data. Includes dimensionality reduction (t-SNE / UMAP) for visualization and cluster interpretation to surface key themes.

`NLP` `scikit-learn` `K-Means` `t-SNE` `NLTK` `Jupyter`

---

### 🐘 [WAF RAG Chatbot](https://github.com/Usamamanzoor2/world_animal_foundation_rag_chatbot)
> Retrieval-Augmented Generation chatbot for the World Animal Foundation

A RAG-powered chatbot that enables natural language Q&A over the foundation's knowledge base. Combines semantic vector search with an LLM to deliver grounded, citation-backed answers — eliminating hallucinations with source-level accountability.

`LangChain` `RAG` `Vector Store` `Embeddings` `FastAPI` `ChromaDB / Pinecone`

---

### 📈 [Market Research Agents](https://github.com/Usamamanzoor2/markeet_research_agents)
> Multi-agent AI system for automated market intelligence

A collaborative multi-agent framework where specialized agents — Trend Scout, Competitor Intel, Sentiment Analyst, and Strategy Synthesizer — autonomously gather, analyze, and compile comprehensive market research reports from a single query.

`LangGraph` `Multi-Agent` `Web Search` `LLM` `FastAPI`

### 🎬 [Text-to-Video Fullstack](https://github.com/Usamamanzoor2/text-2-video-fullstack)
> Full-stack application for AI-powered text-to-video generation

An end-to-end web platform where users submit text prompts and receive AI-generated videos. Features a React frontend with real-time generation progress, a FastAPI backend, and a video management dashboard.

`FastAPI` `React` `PyTorch` `HuggingFace` `Docker`
